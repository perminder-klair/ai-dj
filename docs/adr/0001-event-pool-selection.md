# Select autonomously within an approved event pool

The DJ chooses the playback order from an operator-approved event pool, rather than searching the entire library or following a fixed playlist. For Neon Party Run, the imported playlist is that pool. An operator may search all of Navidrome and queue a listener request outside it. Such a song is downloaded locally and marked request-only: it may play once at the operator's direction but is never offered to autonomous selection or the fallback order. Repeat and artist-spacing checks still apply.
